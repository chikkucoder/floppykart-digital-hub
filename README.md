Build a premium, modern, highly polished and responsive website for an established Indian technology and electronics business called:

Website domain:

floppykart.com

Business established:

Since 2014

IMPORTANT BUSINESS CONTEXT:

FloppyKart is an established technology and electronics shop operating since 2014.

The business deals in:

• Laptop sales

• Desktop sales

• Computer hardware

• Processors

• Motherboards

• RAM

• SSD / Storage

• Computer accessories

• CCTV sales

• CCTV installation

• Networking solutions

• Printer sales

• Printer repair/service

• Laptop repair

• Desktop/computer repair

• CCTV repair/service

• LED TV sales

• Antivirus software

• Quick Heal Antivirus Pro

• Power supplies / SMPS

• ATX12V power supplies

• Other computer hardware and IT products

• Processor

• Motherboard

• ATX12V / SMPS

• RAM

• Other PC components

IMPORTANT FUTURE REQUIREMENT:

This website will eventually become a complete e-commerce platform.

In the future, customers should be able to:

• Browse products

• View product details

• Add products to cart

• Checkout

• Enter customer/address details

• Select payment method

• Make online payment

• Place orders

• Receive order confirmation

• Track orders

Admin functionality will also be added in the future for:

• Product management

• Product images

• Pricing

• Inventory

• Orders

• Customers

• Payments

BUT DO NOT IMPLEMENT ANY DATABASE, BACKEND, AUTHENTICATION, PAYMENT GATEWAY OR REAL E-COMMERCE FUNCTIONALITY RIGHT NOW.

CURRENT PHASE = FRONTEND/UI/UX ONLY.

However, design and structure the frontend in a way that it can easily be converted into a full e-commerce application later.

TECH STACK:

• Next.js

• TypeScript

• Tailwind CSS

• Modern component architecture

• Responsive design

• Clean reusable components

• SEO-friendly structure

• Use modern animations

• Use Framer Motion or an appropriate lightweight animation solution where useful

DESIGN DIRECTION:

The website should look like a combination of:

Premium technology company

+

Modern electronics store

+

Future-ready e-commerce platform

DO NOT make it look like a cheap local computer-shop website.

The website should feel trustworthy, established and premium.

VISUAL STYLE:

• Premium dark navy / black + electric blue technology theme

• White/light sections where appropriate

• Modern typography

• Large professional hero section

• Glassmorphism only where it improves the design

• Soft gradients

• Subtle shadows

• Rounded cards

• Premium product cards

• Smooth hover effects

• Micro-interactions

• Scroll animations

• Image zoom on product cards

• Button hover animations

• Smooth section transitions

Do NOT overuse animations.

The website should remain fast, professional and conversion-focused.
